# hr-analytics-dashboard
Developed an HR Analytics Dashboard using Power BI to analyze employee data and identify key HR trends. The dashboard provides insights into employee attrition, attrition rate, active employees, average age, department-wise attrition, gender-wise attrition, education field-wise attrition, and job satisfaction. 
# HR Analytics Dashboard – Power BI

## Project Overview

This project analyzes employee data using Microsoft Power BI to understand
employee attrition, department-wise employee distribution, job satisfaction,
education field-wise attrition, and gender-wise attrition.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## Dashboard KPIs

- Total Employees: 1,470
- Attrition: 237
- Attrition Rate: 16.12%
- Active Employees: 1,233
- Average Age: 36.92

## Dashboard Analysis

The dashboard provides insights into:

- Department-wise attrition
- Education field-wise attrition
- Gender-wise attrition
- Employee distribution by department
- Job satisfaction rating
- Overall employee attrition

## Key Insights

- Overall employee attrition rate is 16.12%.
- Research & Development has the highest employee count.
- Attrition can be analyzed across departments, education fields,
  and gender.
- Job satisfaction ratings provide additional insight into employee behavior.
